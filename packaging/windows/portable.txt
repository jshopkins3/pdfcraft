CommandPDF portable mode

While this file sits next to command-pdf.exe, CommandPDF keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the CommandPDFData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move CommandPDF with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\CommandPDF and
%LOCALAPPDATA%\CommandPDF) instead. If CommandPDFData can't be written (for example on a read-only
drive), CommandPDF says so and uses the per-user folders instead.
