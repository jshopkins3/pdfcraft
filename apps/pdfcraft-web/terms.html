Command PDF company pilot

Command PDF is MCM's branded fork of PdfCraft. The open-source code and dependencies retain their existing licenses and notices, included with the application package. Command names and marks belong to My Community Mortgage.

This is a small browser pilot. Review saved and printed results before relying on them. Browser OCR, certificate signing, cloud save-back, and advanced or complex document workflows have not been accepted for this pilot.

Use synthetic test documents during client qualification. Follow existing company policies when the pilot is accepted for staff use.
